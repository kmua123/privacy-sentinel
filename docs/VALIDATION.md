# 公开预览版验证范围

日期：2026-11-15；应用版本 0.2.4-preview，versionCode 9，minSdk 29，targetSdk 36。

## 已验证

- Android debug / release 构建成功，lint 0 errors，509 warnings（继承代码及列表刷新等提示仍待逐步清理）。
- 共享逻辑的 Clash 配置回归 72 项、订阅/配置快照回归 75 项通过；包括并发切换时 YAML、DNS 与地址族的一致性。公开版另外移除个人默认值。
- 公共路径构建的完整 Go 回归通过；转发核心与 Java API 保持一致。
- 双 ABI 原生核心每个 PT_LOAD 均为 0x4000 对齐，其他随包原生库也做相同检查；这不等于已在所有 16KB 系统完成运行验证。
- APK 全部条目经个人路径、用户名、私人网络、域名和设备标记扫描，无匹配。
- APK 仅分发 arm64-v8a、x86_64，附本项目隐私说明、第三方许可与来源文本。
- 公开版默认初始化沿用 0.2.3-preview 在 Android 16 x86_64 模拟器清空数据后的验证：没有预置订阅或家庭网络。0.2.4-preview 在同一模拟器覆盖安装，启动守卫及读取新诊断 API 正常；公开默认值经源码复核仍为空。
- 同源码 0.2.4 模拟器验证：禁用 IPv6 后系统 VPN 不再有 fd99 IPv6 地址，仍保留 ::/0 接管；明确启用后地址恢复，同族重载继续复用接口。
- 模拟器第二测试应用 HTTP 在审批前阻断（126ms，HTTP 服务没有收到请求）；明确允许该应用后得到 HTTP 200（951ms）。只读故障诊断页面可读取新原生 API。
- Z9 特定 OpenWrt Wi-Fi 场景已验证：0.2.3 仅过滤 AAAA 后仍复发；0.2.4 同步地址族后头像、封面及进入直播间恢复，关闭 Wi-Fi 再连接同一 AP 后仍正常。未改动路由器配置。这是有限场景结果，不构成所有故障均由 IPv6 导致的证明。

## 限制

尚未完成各品牌、各 Android 版本及 16KB 系统的完整设备矩阵。学校 Wi-Fi、代理服务器、家庭路由/转发及 DNS 的实际表现取决于具体网络。HTTPS 204 延迟不代表带宽或所有网站可达；网页访问成功不意味着支持 ICMP Ping。

诊断的 DNS 日志/错误分类是 best-effort，可能重叠或丢弃，不覆盖所有缓存命中、HTTPDNS 或加密内容；允许检查次数不代表成功连接。公开测试样例中的证书/密钥来自 Mihomo 上游公开 fixture，不是用户凭据。公开包不含开发者发布私钥、用户订阅、ADB/ZeroTier 私钥、手机转储或个人版 Git 历史。
