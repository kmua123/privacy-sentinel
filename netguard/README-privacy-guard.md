# 隐私哨兵 0.2.3-preview

单个 Android VPN 统一处理应用联网审批、Clash 节点代理和原生 ZeroTier 回家。应用 ID `local.privacy.guard`，Android 10+，arm64-v8a / x86_64。内置无线 ADB 与传感器监听需要 Android 11+。

## 使用

首页启动联网守卫后，本用户进入该 VPN 的应用自动纳入，不需逐个添加。独立应用默认首次联网询问，等待期间丢弃请求，批准后原应用需要重试。首次应用审批允许范围是该应用全部联网目标，也可改成按 IP、端口、协议分别审批。支持临时允许十分钟、始终允许、拒绝、阻断、记录及撤销规则。

共享 UID 和低编号系统 UID 默认记录放行，可按整组改成阻断或询问；归属未知的应用 UID 默认阻断。共享 UID 不能精确分成单个包拦截。App 自身为配对、订阅和隧道控制排除在 VPN 外。系统服务代发、其他用户或分身、基带及系统绕过 VPN 的行为不属于完整可观测范围。

审批在 DNS 劫持及直连、代理、ZeroTier 出口之前执行。撤销授权或更改策略保守关闭已有连接，可能使其他应用短暂重连。持续 TCP 读写和 UDP 数据报重新检查授权。核心重载保留 TUN，启动失败保留阻断；若进程被系统终止，需要在 Android VPN 设置启用“始终开启 VPN”和“阻止未使用 VPN 的连接”获得系统断线保护。

## 代理与回家

网络设置支持 HTTPS 订阅或文件导入 `proxies` 列表、节点提供器的 `payload` 列表，再选择出口。仅保留支持的节点字段，不接受订阅控制本机 DNS、VPN、外部监听、远程控制或审批规则。仅含远程 `proxy-providers` 地址的配置及 Base64 URI 订阅暂不支持。订阅地址可能含私人令牌。

“订阅管理与切换”可保存多个 HTTPS 订阅，分别缓存节点和上次选择；切换缓存无需重新下载，更新失败保留旧配置。地址保存在应用私有目录，列表只展示名称。文件导入单独保存，不覆盖其他订阅。切换会重载运行中的网络核心，已有连接可能需要重试。

“节点延迟测试”支持单个或批量测试，最多三个节点同时请求固定 HTTPS 204 地址；显示完成真实代理 TCP、TLS、HTTP 请求的耗时，不能代表下载速度。失败和超时分别显示，不提供虚假 Ping。需先启动联网守卫，不自动切换最快节点。

智能分流先匹配家庭网段并交给 ZeroTier，再按安装包内置的国内域名和 IP 规则直连，其余流量交给所选节点；未选择节点时其余公网直连。国内域名和节点地址引导使用直连 DNS，其他域名经所选节点查询。规则为固定版本的 MetaCubeX/meta-rules-dat 数据，来源、校验值和 GPL 许可证保存在 assets/rules 中；运行时不下载规则。

回家出口模式把全部获准流量和 DNS 交给家庭网关，要求网关支持转发、NAT 与出口策略。现有家庭网络只有已确认的 IPv4 地址和路由，此模式不提供 AAAA／IPv6 出口；TUN 仍接管 IPv6，防止绕过。家庭 DNS 同时使用隧道内的 UDP 和 TCP。出口不可用时连接失败，不自动改为直连。

Wi-Fi、移动数据及底层地址、DNS、路由变化会触发防抖重连，保留原 TUN、应用审批和 ZeroTier 身份；已有连接可能短暂重连。原生出口套接字绑定系统当前默认物理网络，不主动选择移动数据。诊断页显示底层网络类型、系统验证／认证状态和恢复记录，不显示 SSID 或物理 IP。

默认 ZeroTier 自动尝试直连及公共 TCP 备用通道。“回家 TCP 兼容模式”是手动的强制 TCP 中继测试选项，可能降低速度，也不保证当前网络允许该协议；不改变 VPS 或校园网配置。本版不再模拟远端 Ping 应答，暂不支持经回家通道的 ICMP Ping，请用实际网页、文件或 TCP 连接验证可达性。

公开版默认关闭 ZeroTier，不预置任何个人网络、订阅或节点。需要用户填写自己的网络 ID、家庭网段和 DNS；启动后在自己的控制器中授权新节点。官方客户端旧节点授权不会转移。秘密身份保存在本机不备份目录。显示节点 ID 不能证明已授权或已连通，需访问家庭地址验证。

## 无线 ADB 与隐私提醒

无需另装 Shizuku。在“内置无线调试激活”开始通知配对，再到开发者选项开启无线调试并打开配对码弹窗。保持弹窗打开，下拉通知栏输入六位配对码。自动发现本机端口，实际连接固定使用回环地址。手动备用方式需要分屏，配对端口与连接端口不同。

辅助进程仅提供 UID 流量快照和相机、麦克风 AppOps 监听，不提供任意 shell 命令接口。启动令牌随机且短暂，ADB 私钥经 Android Keystore 加密保存；配对码不保存。重启或辅助进程中断后需重新激活，联网审批本身不依赖此服务。

激活后分别在全局流量监看、传感器提醒页面启动功能。系统流量约每三十秒采样，首轮建立基线。外发增量、敏感访问、用户关注组件只是核查线索。相机／麦克风提醒依赖 ROM 标准 AppOps 事件，是使用开始后的提醒；每次事前批准仍受 Android 系统权限机制限制。

系统 UID 计数不可读时，运行中的统一 VPN 可提供自己的转发计数作为备用。页面会标明数据来源，切换来源或重新启动核心后重新建立基线。VPN 备用计数只覆盖经本 VPN 实际转发的应用流量，未观测到的应用不会被当成零流量或安全。网络设置的“回家状态与诊断”提供公开节点 ID、分配地址和路径数量，供不接电脑时排查；不包含私钥和订阅令牌。

最多保存最近 120 组联网记录、60 条传感器事件。HTTPS 内容不可见，目标地址或发送量不能证明窃取了哪些信息。项目未添加分析 SDK。

## 构建与许可

源码包包含 `netguard` 和相邻的 `guard-core`。按后者 README 使用 Go 1.27.4、NDK r27d、JDK 17+ 构建 AAR，复制到 `netguard/app/libs/guardcore.aar`。Android 项目使用 SDK Platform 37、target 36，设置 `JAVA_HOME`、`ANDROID_HOME` 后执行 `gradlew.bat :app:assembleRelease`。APK 需自行签名，覆盖升级需要原证书。源码包不含用户订阅、ADB／ZeroTier 私钥或发布签名。

派生自 NetGuard（GPL-3.0），新转发路径使用修改后的 Mihomo v1.19.33 与其原生 ZeroTier 依赖。完整补丁源码、上游 LICENSE 随包提供，Go 依赖由 go.mod / go.sum 固定。无线 ADB 使用 libadb-android 3.1.1，TLS 使用 Conscrypt 2.5.3，YAML 使用 SnakeYAML 2.7，各自保留许可证。旧 NetGuard JNI 库供原代码加载，统一 VPN 不使用其旧转发服务。
